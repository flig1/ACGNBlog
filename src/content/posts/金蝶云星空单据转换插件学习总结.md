# 金蝶云星空单据转换插件学习总结

## 1. 引言

### 1.1 术语定义

- **单据转换**：将上游所选单据，按照转换规则，自动生成下游单据数据包的过程
- **下推**：在上游单据列表，把所选单据，生成下游单据数据包，并展示出来
- **选单**：在下游单据新增界面，弹出上游单据列表，选择源单返回，然后根据转换规则把源单数据填写到下游单据新增界面上
- **插件**：介入到单据转换的各个关键时刻，对转换行为进行控制的自定义代码

## 2. 核心概念

### 2.1 单据转换原理

单据转换是K/3 Cloud系统中实现业务流程衔接的重要机制，通过预定义的转换规则，实现不同单据之间的数据自动迁移和转换。转换过程不对下游单据进行保存、提交、审核等处理，只生成数据包。

### 2.2 下推与选单的区别

| 特性 | 下推 | 选单 |
|------|------|------|
| 发起方 | 上游单据列表 | 下游单据新增界面 |
| 流程 | 直接生成下游单据数据包 | 先筛选源单，再生成数据包 |
| 触发事件 | 完整的事件序列 | 分为选单前和选单后两个阶段 |
| 应用场景 | 主动生成下游单据 | 基于下游单据需求选择源单 |

### 2.3 单据转换的基本流程

1. 初始化变量
2. 构建读取源单数据参数
3. 设置需要读取的源单字段
4. 设置源单过滤条件
5. 拼接源单内码过滤条件
6. 读取源单数据
7. 对源单数据进行分组
8. 构建目标单空数据包
9. 源单数据迁移到目标单
10. 记录关联关系并进行单位换算
11. 执行表单服务策略
12. 返回目标单据数据包

### 3.1 创建单据转换插件类库

**项目命名规范**：[开发商].K3[.业务领域][.子系统].ConvertPlug

到K/3 Cloud安装目录的WebSite\Bin子目录，引用如下组件：

- Kingdee.BOS.App.dll

## 4. 插件启用与配置

### 4.1 插件编译与部署

1. 编写完插件代码后，编译生成DLL文件
2. 将生成的类库文件(*.dll)复制到K/3 Cloud安装目录的WebSite\Bin子目录

### 4.2 BOS设计器中的配置

1. 进入BOS设计器，打开单据转换主界面
2. 找到对应的转换规则
3. 去掉启用选项
4. 修改插件策略，注册新插件
5. 重新启用转换规则

### 4.3 部署包制作

利用BOS设计器制作部署包时，需要在部署向导中加入：

- 生成的转换插件类库文件(*.dll)
- 自定义(或扩展)的单据转换规则

## 5. 公共属性详解

### 5.1 Context

**作用**：用户登录上下文，记录当前登录用户、数据连接等信息

**语法**：

```csharp
public Context Context { get; }
```

**使用场景**：调用各种服务函数时，需传入本对象作为参数

### 5.2 OperationNumber

**作用**：操作编码标识，区分选单操作和下推操作

**语法**：

```csharp
public string OperationNumber { get; }
```

**取值**：

- "Push"：下推操作
- "Draw"：选单操作

### 5.3 OperationResult

**作用**：单据转换结果信息

**语法**：

```csharp
public ConvertOperationResult OperationResult { get; }
```

**功能**：管理单据转换结果，包括提示信息、成功生成的目标单据数据包

### 5.4 Option

**作用**：额外业务控制选项

**语法**：

```csharp
public OperateOption Option { get; }
```

**功能**：调用下推引擎时，额外传递的一些参数字典，如是否整单下推、是否需要校验下游单据新增权限等

#### 6.1.2 核心事件详解

**OnInitVariable**

- **触发时机**：初始化变量之后
- **作用**：初始化插件变量，调整转换规则
- **参数**：InitVariableEventArgs (包含Context、Rule、SourceBusinessInfo、TargetBusinessInfo)

**OnQueryBuilderParemeter**

- **触发时机**：取源单数据参数初始化完毕后
- **作用**：追加需要加载的源单字段
- **参数**：QueryBuilderParemeterEventArgs (包含SelectItems等)

**OnInSelectedRow**

- **触发时机**：把所选的源单内码转换为取数条件后
- **作用**：修改取数条件，完善内码筛选条件
- **参数**：InSelectedRowEventArgs (包含InSelectedRowsSQL等)

**OnParseFilter**

- **触发时机**：解析完转换规则的选单条件策略之后
- **作用**：修改取数条件，完善选单条件策略中设置的条件
- **参数**：ParseFilterEventArgs (包含FilterPolicySQL等)

**OnBeforeGetSourceData**

- **触发时机**：调用取数服务，读取源单数据之前
- **作用**：干预查询源单数据的过滤对象
- **参数**：BeforeGetSourceDataEventArgs (包含QueryObject等)

**OnGetSourceData**

- **触发时机**：执行取数SQL，获取到了源单数据之后
- **作用**：对源单数据进行处理，如拆单等
- **参数**：GetSourceDataEventArgs (包含SourceData等)

**OnBeforeGroupBy**

- **触发时机**：读取源单数据之后，开始分组之前
- **作用**：修改分组字段，调整分组策略
- **参数**：BeforeGroupByEventArgs (包含HeadGroupKey等)

**OnCreateTarget**

- **触发时机**：对源单分组完毕，创建目标单据数据包之后
- **作用**：完善目标单据字段默认值
- **参数**：CreateTargetEventArgs (包含TargetExtendedDataEntities等)

**OnBeforeFieldMapping**

- **触发时机**：开始字段数据迁移之前
- **作用**：开启字段迁移事件
- **参数**：BeforeFieldMappingEventArgs (包含FireFieldMappingEvent)

**OnFieldMapping**

- **触发时机**：计算完目标单据的字段值，准备填写之前
- **作用**：监控、修正目标字段值
- **参数**：FieldMappingEventArgs (包含MapValue等)

**OnAfterFieldMapping**

- **触发时机**：迁移完字段值之后
- **作用**：处理未设置映射关系的字段
- **参数**：AfterFieldMappingEventArgs (包含TargetExtendDataEntitySet等)

**OnCreateLink**

- **触发时机**：字段迁移完毕，创建关联关系前
- **作用**：控制是否创建关联关系
- **参数**：CreateLinkEventArgs (包含Cancel等)

**OnAfterCreateLink**

- **触发时机**：关联关系子表创建并填写完毕之后
- **作用**：调整关联关系子表内容
- **参数**：CreateLinkEventArgs

**AfterConvert**

- **触发时机**：单据转换完成之后
- **作用**：对转换结果进行最终处理
- **参数**：AfterConvertEventArgs

### 7.3 简单生产领料下推退料单

**需求**：追加条件：可退数量大于0

**实现**：在OnInSelectedRow事件中，修改InSelectedRowsSQL

```csharp
public override void OnInSelectedRow(InSelectedRowEventArgs e)
{
    if (this.IsPush)
    {
        List<ListSelectedRow> SelectedRows = e.SelectedRows.ToList();
        if (SelectedRows != null && SelectedRows.Count() > 0)
        {
            string strFilterSql = string.Empty;
            //简单生产领料单
            if (SelectedRows[0].FormID.Equals("SP_PickMtrl"))
            {
                strFilterSql = " (FActualQty - FSelPrcdReturnQty) > 0 ";
                e.InSelectedRowsSQL = e.InSelectedRowsSQL + (string.IsNullOrWhiteSpace(e.InSelectedRowsSQL) ? "" : " AND ") + strFilterSql;
            }
        }
    }
}
```

### 7.4 采购订单入库

**需求**：追加条件：收料组织不能为空

**实现**：在OnParseFilter事件中，修改FilterPolicySQL

```csharp
public override void OnParseFilter(ParseFilterEventArgs e)
{
    string strFilter = string.Empty;
    string strDesc = string.Empty;
    switch (this.OperationNumber.ToUpperInvariant())
    {
        case "DRAW":
            strFilter = string.Format(" (ISNULL(FRECEIVEORGID,0) = {0} Or ISNULL(FRECEIVEORGID,0) = 0)", stockOrgId);
            break;
        case "PUSH":
            strFilter = " ISNULL(FRECEIVEORGID,0) >　0 ";
            strDesc = "收料组织不能为空";
            break;
        default:
            break;
    }
    if (string.IsNullOrWhiteSpace(e.FilterPolicySQL))
    {
        e.FilterPolicySQL = strFilter;
    }
    else
    {
        e.FilterPolicySQL += " AND " + strFilter;
    }
    if (string.IsNullOrWhiteSpace(e.PlugFilterDesc))
    {
        e.PlugFilterDesc = strDesc;
    }
    else
    {
        e.PlugFilterDesc += strDesc;
    }
}
```

### 7.7 采购订单变更

**需求**：根据选项确定价格取值来源，记录变更单来源为下推

**实现**：

1. 在OnFieldMapping事件中，根据源单是否含税确定价格取值
2. 在OnAfterFieldMapping事件中，设置是否下推标志

```csharp
public override void OnFieldMapping(FieldMappingEventArgs e)
{
    if (e.TargetField.Key == "FOPrice" | e.TargetField.Key == "FNPrice")
    {
        List<DynamicObject> sourceDatas = e.ExtendedDataEntity["ConvertSource"] as List<DynamicObject>;
        if(sourceDatas.Count>0)
        {
            DynamicObject sourceObj=sourceDatas[0];
            if (Convert.ToBoolean(sourceObj["FIsIncludedTax"]))
            {
                e.MapValue = sourceObj["FTaxPrice"];
            }
            else
            {
                e.MapValue = sourceObj["FPrice"];
            }
        }
    }
}

public override void OnAfterFieldMapping(AfterFieldMappingEventArgs e)
{
    ExtendedDataEntity[] heads = e.TargetExtendDataEntitySet.FindByEntityKey("FBillHead");
    if (heads == null)
    {
        return;
    }
    foreach (ExtendedDataEntity head in heads)
    {
        head.DataEntity["FIsConvert"] = true;
    }
}
```

## 8. 最佳实践

### 8.1 插件开发规范

1. **命名规范**：遵循[开发商].K3[.业务领域][.子系统].ConvertPlug命名规范
2. **代码风格**：保持与K/3 Cloud系统代码风格一致
3. **注释规范**：为关键方法和复杂逻辑添加详细注释
4. **异常处理**：合理处理可能出现的异常情况

### 8.2 性能优化建议

1. **字段加载**：只加载必要的源单字段，避免加载过多字段影响性能
2. **数据处理**：对大量数据的处理要考虑分批处理
3. **缓存使用**：合理使用缓存，避免重复计算
4. **SQL优化**：优化查询条件，避免全表扫描

### 8.3 常见问题及解决方案

**问题1**：插件不被触发

- **原因**：插件未正确注册或转换规则未启用
- **解决方案**：检查插件注册和转换规则状态

**问题2**：字段映射不正确

- **原因**：字段映射策略配置错误或插件逻辑问题
- **解决方案**：检查映射策略配置，调试插件逻辑

**问题3**：数据分组不符合预期

- **原因**：分组策略配置错误或插件未正确设置分组字段
- **解决方案**：检查分组策略，在OnBeforeGroupBy事件中调整分组字段

**问题4**：性能问题

- **原因**：加载字段过多或数据处理逻辑复杂
- **解决方案**：优化字段加载，简化处理逻辑
