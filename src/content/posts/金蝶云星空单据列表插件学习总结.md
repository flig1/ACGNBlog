# 单据列表插件复习文档

## 1. 引言

### 1.1 术语定义

| 术语          | 解释                                                   |
| ------------- | ------------------------------------------------------ |
| 单据列表插件  | 继承自 AbstractListPlugIn 的插件，用于扩展单据列表功能 |
| ListModel     | 列表模型层接口，负责数据处理和业务逻辑                 |
| ListView      | 列表视图层接口，负责界面显示和用户交互                 |
| 模型-视图分离 | 插件架构设计模式，将数据处理和界面显示分离             |
| 事件          | 插件中用于响应特定操作的方法                           |
| 下推          | 从源单据生成目标单据的操作                             |
| 上查/下查     | 查看单据上下游关联关系的操作                           |

## 2. 核心概念

### 2.1 单据列表插件概述

单据列表插件是金蝶云星空 BOS 平台中用于扩展单据列表功能的插件类型，继承自 AbstractListPlugIn 基类。它实现了 IlistViewPlugIn 和 IlistModelPlugIn 两个接口，分别负责视图层和模型层的功能。

### 2.2 插件架构（模型-视图分离）

单据列表插件采用模型-视图分离的设计架构：

- **模型层（ListModel）**：负责数据处理、业务逻辑和数据访问
- **视图层（ListView）**：负责界面显示、用户交互和数据格式化

这种架构使得插件代码更加清晰，职责分明，便于维护和扩展。

### 2.3 开发流程

1. 创建插件类库工程
2. 引用 BOS 平台组件（website\bin 目录下）
3. 修改插件类库编译输出路径为 website\bin
4. 创建插件类，继承 AbstractListPlugIn
5. 实现必要的事件方法
6. 在 BOS 设计器中配置单据列表插件

## 3. 公共属性详解

### 3.1 ListModel

- **描述**：模型层访问接口，通过 Model 属性做强制转换

- **语法**：

  ```csharp
  public virtual IListModel ListModel
  {
      get
      {
          if (this.Model != null && this.Model is IListModel)
          {
              return (IListModel)this.Model;
          }
          else
          {
              return null;
          }
      }
  }
  ```

#### 3.1.1 常用属性

| 属性名           | 描述                                                         |
| ---------------- | ------------------------------------------------------------ |
| BillBusinessInfo | 关联单据的业务逻辑元数据                                     |
| FieldKeyMap      | 列表上显示的字段，其字段名 FieldName 和字段标识 Key 的对应关系 |
| FilterParameter  | 列表过滤条件参数对象                                         |
| GlobalParameter  | 单据参数配置中配置的单据全局参数                             |
| ParameterData    | 用户参数数据，一般是选项菜单界面的配置数据                   |
| Header           | 列表表头对象                                                 |
| QueryInfo        | 列表查询元数据，包括组织隔离字段、可供查询的实体、字段列表等 |
| Limit            | 每页行数                                                     |
| StartRow         | 开始行索引                                                   |

#### 3.1.2 常用方法

| 方法名                                                       | 描述                                   |
| ------------------------------------------------------------ | -------------------------------------- |
| GetData(int startRow, int limit, bool needRefreshTree)       | 获取列表数据                           |
| GetData(int start, int rows, bool needRefreshTree, string orderInfo) | 获取列表数据，带排序                   |
| GetRow(IDataRow r)                                           | 获取选中行对象                         |
| GetGroupInfo(string groupRows)                               | 获取分组信息                           |
| GetHeadFieldSummaryData(List<Field> summaryHeadFields)       | 获取单据头字段的汇总数据               |
| GetSummaryData(List<Field> summaryFields)                    | 获取汇总数据（单据体）                 |
| GetPagingRowCount()                                          | 列表总行数，为了性能，仅在最后一页取数 |
| GetPKData()                                                  | 获取当前列表查询的所有主键数据         |
| GetRowCount()                                                | 获取列表总行数和单据记录数             |
| Refresh()                                                    | 刷新列表                               |
| RefreshByFilter()                                            | 根据过滤条件，重新取数，刷新列表       |

### 3.2 ListView


#### 3.2.1 常用属性

| 属性名                 | 描述                                          |

## 4. 事件系统详解

### 4.1 事件分类

单据列表插件的事件可分为以下几类：

- **初始化事件**：ListInitialize
- **数据处理事件**：AfterGetData, PrepareFilterParameter
- **界面交互事件**：ListRowDoubleClick, BarItemClick
- **数据格式化事件**：FormatCellValue, OnFormatRowConditions
- **单据转换事件**：OnGetConvertRule, OnShowConvertOpForm
- **上下查事件**：OnShowTrackResult

### 4.2 常用事件详解

#### 4.2.1 AfterGetData

- **触发时机**：列表取数完成后，在数据发送到前端之前触发

- **应用场景**：列表取数后的数据处理，如数据为空时的处理

- **示例代码**：

  ```csharp
  public override void AfterGetData()
  {
      base.AfterGetData();
      if (this.ListView.CurrentPageRowsInfo.Count < 1)
      {
          // 数据为空时的处理逻辑
      }
  }
  ```

#### 4.2.2 FormatCellValue

- **触发时机**：列表显示，在获取数据之后，数据发送到前端之前触发

- **应用场景**：格式化列表单元格数据，如精度控制、特殊显示等

- **示例代码**：

  ```csharp
  public override void FormatCellValue(FormatCellValueArgs args)
  {
      base.FormatCellValue(args);
      if (args.Header.FieldName.Equals("FRATE", StringComparison.OrdinalIgnoreCase))
      {
          if (args.Value != null)
          {
              args.FormateValue = Convert.ToDecimal(args.Value).ToString("#.00");
          }
      }
  }
  ```

#### 4.2.3 ListInitialize

- **触发时机**：列表初始化时触发

- **应用场景**：初始化时获取参数、设置初始状态等

- **示例代码**：

  ```csharp
  public override void ListInitialize(ListInitializeEventArgs e)
  {
      base.ListInitialize(e);
      bool openByAdjust = Convert.ToBoolean(e.Paramter.GetCustomParameter("OpenByAdjust"));
  }
  ```

#### 4.2.4 ListRowDoubleClick

- **触发时机**：双击列表行时触发

- **应用场景**：双击时的特殊处理，如条件判断、自定义操作等

- **示例代码**：

  ```csharp
  public override void ListRowDoubleClick(ListRowDoubleClickArgs e)
  {
      object isPriceListQuery = this.View.OpenParameter.GetCustomParameter("IsPriceListQuery");
      if (isPriceListQuery != null)
      {
          e.Cancel = true;
      }
  }
  ```

#### 4.2.5 OnGetConvertRule

- **触发时机**：选单/下推过程，获取单据转换规则时触发

- **应用场景**：自定义单据转换规则，如指定特定的转换规则

- **示例代码**：

  ```csharp
  public override void OnGetConvertRule(GetConvertRuleEventArgs e)
  {
      base.OnGetConvertRule(e);
      if (e.ConvertOperation == FormOperationEnum.Push && e.TargetFormId == "SP_PickMtrl")
      {
          // 自定义转换规则逻辑
      }
  }
  ```

#### 4.2.6 OnShowConvertOpForm

- **触发时机**：下推过程中，展示可选目标单据时触发

- **应用场景**：调整可选的单据类型，如筛选掉某些单据类型

- **示例代码**：

  ```csharp
  public override void OnShowConvertOpForm(ShowConvertOpFormEventArgs e)
  {
      if (e.ConvertOperation == FormOperationEnum.Push)
      {
          var bills = e.Bills as List<ConvertBillElement>;
          if (bills != null && bills.Count > 0)
          {
              e.Bills = bills.Where(c => !c.FormID.Equals("FA_CARD", StringComparison.OrdinalIgnoreCase)).ToList();
          }
      }
  }
  ```

#### 4.2.7 OnShowTrackResult

- **触发时机**：上/下查过程，获得上/下查结果时触发

- **应用场景**：调整上/下查结果，如替换显示内容

- **示例代码**：

  ```csharp
  public override void OnShowTrackResult(ShowTrackResultEventArgs e)
  {
      base.OnShowTrackResult(e);
      if (e.TrackOperation == FormOperationEnum.TrackUp)
      {
          // 调整上查结果的逻辑
      }
  }
  ```

#### 4.2.8 PrepareFilterParameter

- **触发时机**：打开单据列表，构建取数用的 SqlBuilder 对象前触发

- **应用场景**：修改列表过滤条件、排序子句等

- **示例代码**：

  ```csharp
  public override void PrepareFilterParameter(FilterArgs e)
  {
      if (this.View.ParentFormView.UserParameterKey != "CRE_CustArchives")
      {
          if (string.IsNullOrWhiteSpace(e.FilterString) == false)
          {
              e.FilterString += " and";
          }
          e.FilterString += " flistdisable<>'1' ";
      }
  }
  ```

### 4.3 事件触发顺序

1. ListInitialize
2. PrepareFilterParameter
3. AfterGetData
4. FormatCellValue
5. OnFormatRowConditions
6. 界面交互事件（如 BarItemClick、ListRowDoubleClick 等）

### 5.4 股权关系列表精度控制案例

**需求背景**：【合并报表参数设置】中有对持股比例精度进行控制，股权关系列表中需要参照该精度显示持股比例值。

**实现方案**：在 OnInitialize 中获取系统参数，在 FormatCellValue 中使用该参数格式化数值。

**关键代码**：

```csharp
private int _ratePrecision = 2;

public override void OnInitialize(InitializeEventArgs e)
{
    base.OnInitialize(e);
    _ratePrecision = CRSystemParamerServiceHelper.GetSystemParamter4CR(this.Context, 0, CRConst.Key_InvestRatePrecision, 2);
}

public override void FormatCellValue(FormatCellValueArgs args)
{
    base.FormatCellValue(args);
    switch(args.Header.FieldName.ToUpperInvariant())
    {
        case "FRATE":
        case "FHISTORYRATE":
            if(args.Value != null)
            {
                string formatString = string.Format("#.{0}", new string('0', _ratePrecision));
                args.FormateValue = Convert.ToDecimal(args.Value).ToString(formatString);
            }
            break;
    }
}
```

## 6. 最佳实践

### 6.1 开发技巧

1. **合理使用 ListModel 和 ListView**：根据职责选择合适的接口，模型层逻辑使用 ListModel，界面相关操作使用 ListView
2. **事件处理顺序**：了解事件触发顺序，合理安排代码逻辑
3. **参数传递**：使用 OpenParameter 或自定义参数传递数据，避免硬编码
4. **异常处理**：在关键操作中添加异常处理，提高插件稳定性
5. **日志记录**：在复杂逻辑中添加日志记录，便于调试和问题排查

### 6.2 性能优化

1. **数据查询优化**：合理使用过滤条件，避免全表扫描
2. **缓存使用**：对于频繁访问的数据，考虑使用缓存
3. **批量操作**：对于批量数据处理，使用批量操作减少数据库交互
4. **分页处理**：对于大数据量列表，使用分页减少数据传输
5. **延迟加载**：对于非必要的数据，使用延迟加载提高响应速度

### 6.3 代码规范

1. **命名规范**：使用有意义的类名、方法名和变量名
2. **注释规范**：为关键方法和复杂逻辑添加注释
3. **代码结构**：保持代码结构清晰，逻辑分明
4. **代码复用**：提取公共方法，避免代码重复
5. **遵循框架**：遵循 BOS 平台的开发规范和最佳实践

### 6.4 常见问题及解决方案

| 问题           | 原因               | 解决方案                                         |
| -------------- | ------------------ | ------------------------------------------------ |
| 插件不触发事件 | 事件方法签名错误   | 检查方法签名是否正确，确保使用正确的参数类型     |
| 列表数据为空   | 过滤条件过于严格   | 检查 PrepareFilterParameter 中的过滤条件         |
| 格式化无效     | 字段名大小写不匹配 | 使用 StringComparison.OrdinalIgnoreCase 进行比较 |
| 下推无目标单据 | 转换规则未配置     | 检查 OnGetConvertRule 事件中的转换规则设置       |
| 双击无反应     | 取消了后续操作     | 检查 ListRowDoubleClick 事件中的 e.Cancel 设置   |
| 性能缓慢       | 数据处理逻辑复杂   | 优化数据处理逻辑，使用缓存和批量操作             |
